# User Story: Improved Speaker Annotation

As a user, who recorded a meeting with two or more participants, I want to be able to download the transcript with speaker annotation, such that I can distinguish who said what in the downloaded transcript file.

## Additional Information

- The recording session page already allows for copying the transcript.
- When copying, the text contains the transcript, but without speaker annotation.
- After this user story is implemented, the transcript should also contain a tag indication the person that spoke.
